# 📦 Inventory Management System using AI

## 📌 Project Overview
This is a simple AI-based Inventory Management System built using PHP, MySQL, HTML, CSS, and JavaScript.  
It helps manage products, stock levels, sales data, and includes smart AI-based stock suggestions.

---


## 🎯 Objectives
- Digitally manage inventory system
- Track stock in/out efficiently
- Store and analyze sales data
- Predict low stock situations
- Reduce manual errors
- Improve business decision making

---
## ✨ Features
### 👨‍💼 Admin Features
- Secure admin login system
- Add / Update / Delete products
- Stock in & stock out management
- Sales record tracking
- Dashboard analytics

### 🤖 AI Assistant Features
- Smart inventory chatbot
- Product search using natural language
- Low stock detection
- Category-wise product listing
- Cheap product suggestions
- Alternative product suggestions when stock is low
- Voice input support (AI chat)

---
## 🧠 AI Logic
The system analyzes product stock and sales data:

- Calculates average usage
- Detects low stock automatically
- Suggests restocking
- Recommends alternative products from same category or type

---
## 📊 System Flow
1. Admin login
2. Product management
3. Stock updates
4. Sales data storage
5. AI analysis
6. Smart suggestions & alerts
